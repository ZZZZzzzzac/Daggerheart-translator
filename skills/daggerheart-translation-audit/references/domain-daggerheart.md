# Daggerheart项目附加检查（按需）

仅在原文属于Daggerheart时使用。项目指定的版本、术语表与已确认翻译口径优先；术语选择仍需结合上下文，不以所有偏离推荐词的译法为错误。

- 主体/目标、攻击与反应掷骰、成功/失败、希望/恐惧条件
- 费用归属、生命/压力/希望/恐惧、物理/魔法/直接伤害
- 距离、目标数、骰型、固定加值、次数、持续时间、冷却与可选/强制
- 核对SRD具体版本；旧SRD、核心书、VTT副本和装备独立文件不自动合并入同一范围
- 正文装备区与结构化装备文件先核对版本与重复关系；混合条目只排除重复片段
- 完整能力段、相邻特性、相关通则是理解条件和代词的重要上下文

ParaTranz适配器操作见 [data-contract.md](data-contract.md)。同样的审阅方法也可以直接用于本地规则书文本，不需要ParaTranz账号。
