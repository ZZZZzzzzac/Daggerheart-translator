# AI 主审翻译流程：试用说明

本分支提供可试用的流程和离线检查，不是对翻译准确率的认证。请先复制自己的项目再试；本仓库不附完整书稿、人工译本、平台快照或真实用户审阅记录。

## 开始试用

```bash
git fetch origin trial/ai-first-context-review-20261009
git switch --track origin/trial/ai-first-context-review-20261009
python -m unittest discover -s tests -v
```

已在本分支时无需重复创建本地分支。Python 检查使用标准库；PDF/OCR 转换所需依赖仍按对应技能另行安装。

按 `AGENTS.md` 安装技能，将 `project/example/` 复制成自己的项目，再把英文文件放入该项目 `source/`。给 AI 的试用任务可以这样写：

> 加载 daggerheart-translation-pipeline，先确认原文范围和运行模式，再完成翻译。AI 先解决普通术语、措辞和可由源文确定的错误，独立核对全部源译文。只有真正未决的问题才交给我，每张问题卡都带完整原文单位与上下文、当前译文、疑点、选项、推荐和理由；同一能力的多个问题合并展示，不合并问题计数。

手动模式保留最终放行。用户明确选用全自动模式时，仍需独立全文审校并披露未决项，不能临时切换模式绕过已有确认。

## 一轮正常流程

1. **确认原文**：确定版本、起止范围、页/节来源；源文件缺失、表格错列与规则本身缺项分别记录。不能从中文参考反推缺失英文，也不能把局部样本称作整卷。
2. **术语分层**：核心表优先，专项表按语义适用，项目词留在项目。六个官方框架名仍在核心表；两份专属机制表仅显式选用。AI 可按语境处理词面差异，不要求用户逐词批准。
3. **翻译并保留结构**：完整传递生成的提示词与写作规范；保留 KILO/术语标记、数字、骰式和原文信息。先写自然中文，再回查含义。
4. **独立全文审校**：所有源译段落都要看，包括没标词、用了推荐词的句子。检查角色/协助者、费用与效果接受者、单复数、条件、否定、比较边界、行动与意愿。泛指复数本身不能证明一次费用作用于多个目标。
5. **AI 修复后重算**：保存原稿和修改依据，修确定错误；记录合理语境例外。任何相关输入变化后刷新摘要，不能把旧审阅哈希换成新值冒充已审阅。
6. **上下文问题卡**：只呈报仍需要判断的事项，完整带材料。忠实保留源文即可交付的规则歧义，与必须先解决才能翻译的阻塞分别计数；来源根本没写的细节只说明缺项，不编造选择题。
7. **清标记与交付**：遵守所选模式的审批门禁；合并、makeup、校验，再按现有模板提取适用的 JSON。正文和规则说明不强行转成卡牌。

## 看什么结果

- 完整审计用于追溯；用户读简短问题卡，不必逐行审查全部词表。
- 同一能力有两个独立问题时，原文和译文各展示一次，下面分别列两个问题。
- 每个问题都说明：具体哪里不确定、不同读法怎样影响结果、AI 推荐哪一种或为何建议保留原文歧义，以及推荐依据。
- 原文、上下文、当前译文或问题集改变后，旧审阅输出不再有效。
- 词面提示数量、问题卡数量、独立问题数量和实际用户决策数是不同指标。不能把少提问或测试全过写成准确率提高。

严格导出：

```bash
# AI 完成修复/审校、刷新术语报告后，生成可准确引用的当前材料
python skills/daggerheart-term-checker/scripts/export_human_review.py <项目目录> --prepare
# AI 按准备材料填写 source/temp/_human_review.json；这不是要求用户填表
python skills/daggerheart-term-checker/scripts/export_human_review.py <项目目录>
```

输出 `source/temp/_human_review_cards.md` 和 `.json`。只有严格导出成功才把卡片交给用户；旧卡片不能在输入改变后继续使用。输入格式、字段含义和合成示例见 [上下文问题卡指南](../skills/daggerheart-term-checker/HUMAN_REVIEW.md)。示例与语义测试均为合成数据，不是官方规则或真实用户批准。

## 兼容性提醒

- 核心术语路径迁移为 `resources/terms-core.json`；已有项目要重新生成合并表。
- `strip_term_markers.py` 默认要求手动批准。只有已明确选全自动流程，才传 `--mode auto`。
- 机器检查负责结构、来源对应、内容绑定和审阅记录格式；语义判断仍由独立审阅承担。
- ParaTranz 功能沿用上游；本分支的本地翻译/测试不需要访问任何线上令牌，也不会自动同步或写回平台。
